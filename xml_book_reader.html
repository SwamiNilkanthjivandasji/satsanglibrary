GitHub પર આ વેબ એપ કેવી રીતે મૂકવી?

તમે તમારી બધી જ XML ફાઇલોને GitHub Repository માં રાખીને મફતમાં GitHub Pages દ્વારા વેબસાઇટ ચલાવી શકો છો. તેના માટે નીચે મુજબ ફોલ્ડર સ્ટ્રક્ચર રાખો:

my-satsang-library/
├── index.html          (આ વેબ એપની ફાઇલ)
├── books/              (તમારી બધી XML ફાઇલો અહીં મૂકો)
│   ├── mahima.xml
│   ├── vachanamrut.xml
│   └── ...બીજી ફાઇલો.xml

નવી XML ફાઇલ ઉમેરવાની રીત:

આ index.html ફાઇલની અંદર જાવાસ્ક્રિપ્ટમાં EXTERNAL_BOOKS_CONFIG નામનું લિસ્ટ આપેલું છે. તેમાં ખાલી તમારી XML ફાઇલનું નામ અને પાથ નીચે મુજબ લખી દો:

const EXTERNAL_BOOKS_CONFIG = [
  {
    id: "book-1",
    title: "મહિમા સાથે નિશ્ચય શા માટે ?",
    category: "સત્સંગ કથા",
    xmlUrl: "books/mahima.xml"
  },
  {
    id: "book-2",
    title: "વચનામૃત",
    category: "શ્રીજી મહારાજના વચનામૃત",
    xmlUrl: "books/vachanamrut.xml"
  }
];

✨ ઓટોમેટિક XML ડિટેક્શન:

તમારે એ ચિંતા કરવાની જરૂર નથી કે XML ફાઇલમાં <sub_chapter> છે કે નહીં! આ એપ આપોઆપ ચેક કરી લેશે:

  • જો ચેપ્ટરની અંદર <sub_chapter> હશે, તો પહેલા સબ-ચેપ્ટરનું લિસ્ટ બતાવશે.
  • જો સીધું <content> હશે, તો ચેપ્ટર પર ક્લિક કરતાની સાથે જ સીધું વાંચન (Content) ખૂલી જશે!
